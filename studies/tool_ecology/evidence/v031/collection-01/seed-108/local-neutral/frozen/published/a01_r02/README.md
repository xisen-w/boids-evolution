# Row table services
Import `clean_service`, `revenue_service`, `group_service`, `monthly_service`, `lookup_service`, or `window_service` from this package. Each accepts `(rows, lookup, request)` and returns fresh row dictionaries (or aggregate rows), leaving inputs unchanged. For example `revenue_service(rows, [], {'fill':'median'})` fills missing units and appends revenue_cents. Clean normalizes region; revenue/window deliberately do not. Group/monthly/lookup normalize regions. Aggregations support sum/mean/count; fill supports zero/mean/median; windows use trailing row count. Missing revenue is excluded from aggregate values.
