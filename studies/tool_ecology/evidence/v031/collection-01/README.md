# Completed recovered exploratory collection

Nine societies, eight agents and six rounds each. All 420 admitted publications
are archived as immutable frozen libraries with generation manifests. Original
batch02 remains aborted; this directory is the sanitized analysis archive for a
separate recovered collection, with all attempts and per-cell provenance.

- `results.csv`: all nine cells; all-six counts describe broad offerings, not a division-of-labour objective.
- `diagnostics.json` and each cell's interventions: 420 replay parities and 71/72 return-intervention witnesses.
- `fresh-panel/`: common new DEV data, author dependency provenance, structural removal and publication results.
- `condition-summary.json`, `final-summary.json`: descriptive summaries; three societies per condition.
- `usage-accounting.json`: valid cells and discarded transport attempt separately; `usage.json` includes all attempts.
- `historical-attempt-costs.json`: earlier engineering and measurement-invalidated costs also retained, not mixed into comparisons.
- `provenance-audit.json`: generation Git blobs and actual API metadata checked on the host; no raw responses published.
- `request-execution-audit.json`: nonempty/empty request counts and the four narrow declarations.
- `narrow-lookup-diagnosis/`: isolated one-line program repair, never an original rescore.
- `unconfirmed-intervention.json`: the selected empty-table edge that supplied no correctness-loss witness.
- `output-differences.json`: descriptive failed output fields, not automatic causal attribution.
- `figures/`, `execution-graphs/`, `provenance-figures/`: PNG, editable SVG and PDF.
- `analysis-manifest.json` and `tests-64.txt`: analysis source hashes and final offline contract verification.

Private model requests, responses, prompts, trajectories and grader input/output
tables stay in the host's ignored run directories. A self-contained profile is
the union over one author's history whose entire declared dependency closure
belongs to that author; it does not prove original authorship or understanding.
Native/reflection/generator execution is incompletely traced. Repeated cases are
not independent societies. The study has no paid single-agent or centralized
baseline. Per-cell original55/recovery180 second waiting is disclosed.
