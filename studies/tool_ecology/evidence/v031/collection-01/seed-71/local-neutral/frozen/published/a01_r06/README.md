# candidate
Native Python, non-mutating transforms for lists of row dictionaries. Public functions are `clean(rows, lookup, request)`, `revenue(...)`, `group(...)`, `monthly(...)`, `lookup(...)`, and `window(...)`. They return lists of dictionaries, preserve input rows (and for row-wise services column insertion order), and do not mutate any arguments. Requests use `fill` (`zero`, `mean`, `median`), `agg` (`sum`, `mean`, `count`), and `window` (row count). Regions are stripped and lowercased; missing-unit all-missing fill is zero. Example: `revenue([{'region':' West ', 'units':2, 'price_cents':30}], [], {'fill':'zero'})` returns the row with normalized region `west` and `revenue_cents: 60`. Grouped outputs contain only grouping and aggregate columns. Lookup uses exact keys after normalization; lookup region keys are normalized with the same strip/lower rule. Dates use the leading seven characters. Inputs are expected to follow the documented opportunity schema; malformed numeric types are not validated.
