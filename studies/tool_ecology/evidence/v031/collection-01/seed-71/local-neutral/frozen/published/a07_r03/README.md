# a07_r03
Dependency-free transforms for list-of-dictionary rows. Public adapters `clean(rows, lookup, request)`, `revenue(...)`, `group(...)`, `monthly(...)`, `lookup(...)`, and `window(...)` return new dictionaries without mutating inputs. Request supports fill=`zero|mean|median`, agg=`sum|mean|count`, and window=2/3/4. Example: `revenue([{'region':' EAST ','units':2,'price_cents':50}], [], {'fill':'zero'})` returns normalized region and revenue 100. Group outputs contain only group keys and aggregate. None is the missing-value representation; malformed non-string dates and malformed numeric operands are outside the input contract.
