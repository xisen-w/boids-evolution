# Row services
Dependency-free Python adapters accepting `(rows, lookup, request)` and returning new row dictionaries/lists; inputs are not mutated. Public functions: `clean`, `revenue`, `group`, `monthly`, `lookup`, `window`. Fill accepts zero/mean/median (all missing becomes zero); aggregates sum/mean/count; window accepts 2, 3, or 4. Clean/group/monthly/lookup normalize region; revenue and window retain it. Aggregation omits missing keys and missing revenue values. Example: `revenue(rows, [], {'fill':'mean'})`. Inputs follow the published row schema; dates are ISO strings.
