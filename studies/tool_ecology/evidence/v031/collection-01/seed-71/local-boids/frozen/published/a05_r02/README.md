# Row services
Public functions `clean(rows, lookup, request)`, `revenue(...)`, `group(...)`, `monthly(...)`, `lookup(...)`, and `window(...)` implement the matching service contracts and return new row dictionaries/lists (aggregate services return aggregate rows). Requests use `fill` zero/mean/median, `agg` sum/mean/count, and `window` 2/3/4. Example: `revenue(rows, [], {'fill':'median'})`. Clean/group/monthly/lookup use the verified `published.a01_r01` implementation; revenue deliberately preserves region as specified, and window uses trailing physical rows. Input tables are expected to be list-of-dicts with numeric operands and specified fields; invalid fill/aggregation/window values raise ValueError. No input is mutated.
