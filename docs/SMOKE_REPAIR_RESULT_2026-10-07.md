## 本次修改

- 移除 solver 胶水代码的物理行数上限。输出 token 预算不变，solver 仍只能组合工具库，不能自己写变换算法。
- 给所有组的 builder 补齐共同的公开数据格式、primitive 参数和功能规范；不提供参考实现、隐藏 probe 或答案。
- 明确 TARGET 表示不传额外参数也能完成整道任务；参数化构件使用 NONE。
- Solver 工具目录显示直接可读的调用签名，避免猜错 `col`、`value` 等参数名。
- 移除“每条 solver 答案都必须合法、否则重启整场”的过度严格停机条件。非法 glue 不执行且记 0；已明确归类的普通 Python 编程错误也保留为失败，不修模型答案、不重新采样。未知执行错误、权限问题、超时、沙箱故障、网关异常仍停止。
- 增加跨重跑持久预算账本、排他锁、哈希链和发送前预留。失败调用不退还预留，不因重启或跨日清零。

这些是开发阶段的修复，不能声称当前版本仍沿用旧的 15 行协议。正式实验应重新冻结最终版本。
